# bookshelf-design-notes

DIYで作った本棚の寸法を記録するための、ブラウザだけで動くツールです。

## 使い方

`index.html` をブラウザで開くだけで使えます（インストール不要）。

- 幅・高さ・奥行き・板厚・棚板の枚数を入れると、正面図と側面図が寸法線つきで描かれます
- 一番下の段は「床をそのまま使う」「地板を入れる」から選べます
- 棚板のはみ出し（側板より長い分）は全部同じ／1枚ずつ指定のどちらでも設定できます
- 木取り表とL字金具の数を自動で計算します

## データの保存（このリポジトリで管理する）

保存した本棚は、このリポジトリの `data/` フォルダに **1棚につき1つのJSONファイル** として保存できます。そのまま `git add` してコミットすれば、変更履歴をGitHubで管理できます。

```
data/
  リビングの文庫本棚.json
  kitchen-shelf.json
```
